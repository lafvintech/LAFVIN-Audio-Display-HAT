# Selected Twemoji Graphics

AI Chatbot loads only these six 72x72 PNG files:

- `1f642.png`: Ready
- `1f442.png`: Listening
- `1f914.png`: Thinking
- `1f600.png`: Speaking
- `2639.png`: request error
- `26a0.png`: configuration error

The remaining `1f602.png`, `1f634.png`, `1f917.png`, and `203c.png` images are
retained as possible future states but are not loaded by AI Chatbot.
