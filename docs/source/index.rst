LAFVIN Audio Display HAT User Guide
===================================

This guide walks you through setting up a new Raspberry Pi, including flashing the
operating system, installing the HAT, configuring the drivers, checking the hardware,
and deploying the runtime. When setup is complete, the device starts automatically
each time the Raspberry Pi boots.

To modify the built-in applications or develop your own, continue to Part 4. You can
use the web simulator in WSL2 to develop most application logic and interactions and
preview the user interface.

For the initial setup, complete the sections in the order shown in the navigation
menu. Do not skip the hardware checks; they can reveal display, audio, or GPIO
connection issues before you configure the AI services.
