LAFVIN Audio Display HAT 用户教程
=================================

本教程帮助你从一块全新的 Raspberry Pi 开始，完成系统烧录、HAT 安装、
驱动配置、硬件检查和 Runtime 部署。完成后，设备会在每次开机时自动启动。

如果希望修改内置应用或开发自己的应用，可继续阅读第四部分，在 WSL2 中通过
Web 模拟器完成大部分应用逻辑、交互和界面预览。

首次安装请严格按左侧目录顺序完成。不要跳过硬件检查；它能在配置 AI 服务
之前发现屏幕、音频或 GPIO 连接问题。
